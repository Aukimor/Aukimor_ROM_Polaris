# Mix2S 三方官改包对比（2026-11-04）

对比对象（均 Android 10 / MIUI 12 / polaris / CN）：
1. **BlueHill** `MIX2S_MIUI12_20.9.4` — 带「高级设置」app 的那个
2. **乌堆** `乌堆包_miui12_20.9.4`
3. **猫咪** `Maomi-Polaris_20.8.27`（版本略旧）

## 官改包通用结构
```
config/              fs_config、file_contexts、WorkConfig
firmware-update/     abl/aop/bluetooth/cmnlib/devcfg/dsp/hyp/keymaster/logo/modem/qupfw/tz/xbl*.img
boot.img             （BlueHill 包独立带 boot.img）
system.new.dat(.br) + system.transfer.list   块数据（brotli 压缩，Maomi 用 .br）
vendor.new.dat(.br) + vendor.transfer.list
META-INF/            update-binary/updater-script + busybox.zip + magisk.zip + magiskboot.sh
Magisk.apk           （部分包）
```
刷机脚本（updateM）逻辑：A/B 动态分区 lptools unmap/map → 音量键选择（装 Magisk / 刷 TWRP）→ Magisk boot patch。

## 三家风格对比
| | BlueHill | 乌堆 | 猫咪 |
|---|---|---|---|
| 精简程度 | 中（101 app / 71 priv） | 中（101 / 72） | **激进（51 / 30）** |
| 自有工具 | **BlueHill「高级设置」**（360 加固）+ xbin/BlueHill + ZPHide | 无自有 app | **Maomi** app |
| 额外大件 | magisk（data-app） | **Brevent（黑域）+ ViPERFX（音效）** + 酷安/智趣车/标准 AR 等 9 个 data-app | 自带计算器/录屏/天气 |
| xbin | busybox + zip/unzip/uninstall | busybox | **无**（最干净） |
| ro.secure | 0 | 0 | 0 |
| services.jar | 5.2MB | 6.5MB | **11.3MB**（异常大，可能大量 smali 补丁） |

## 共同点（官改的"标准动作"）
- 全部 `ro.secure=0`（用户态 adb 默认 root）
- **无一改 sepolicy**（system/etc/selinux 和 vendor/etc/selinux 都是标准文件）→
  严格模式全靠 bootloader cmdline（permissive），没人做 enforcing
- 都是 AonlyDynamic 结构 + data-app 塞私货
- sepolicy 文件数完全一致（12）→ 没人补策略

## 结论
1. 官改 =「官方包解包 → 精简/替换/塞 app → 打卡米补丁 → 改 prop → 重打包」，
   无技术壁垒，全是文件操作（厨房活）
2. 差异只在**精简清单**和**私货清单**——Hais 的 DeleteFileConfig/AddReplaceFile
   完全能表达
3. 想做 enforcing：三家都没做，sepolicy 得自己补（前面调研的
   sepolicy-inject / magiskpolicy 路线）
4. BlueHill 的「高级设置」是 360 加固，静态不可读，功能只能靠行为观察
